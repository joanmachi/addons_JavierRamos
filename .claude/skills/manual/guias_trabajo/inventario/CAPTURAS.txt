# DUDAS A CONFIRMAR EN PANTALLA

1. **(inv-albaran-valorado — PRIORITARIA)** `CAMBIOS.md [003]` describía un server action de impresión
   llamado **"Imprimir Albarán Valorado"** (`binding_type=report`) con método
   `action_print_valued_albaran()` + variable `show_valued`/`force_valued`. **En el código ACTUAL
   ese server action y ese método YA NO EXISTEN**: `stock_picking_report_valued/report/stock_picking_report_valued.xml`
   solo tiene la herencia del template `stock.report_delivery_document`, y `models/stock_picking.py`
   no tiene el método. Es decir, hoy el albarán sale valorado **por la opción estándar "Albarán de entrega"
   (Delivery Slip)** y depende de la casilla `valued_picking` del cliente, NO de una opción propia en Imprimir.

   "Albarán Rectificado" y "Etiqueta"? La guía 1 está escrita asumiendo "Albarán de entrega"; ajustar el
   nombre del paso 5 si en pantalla figura otro texto.
